## 构造柱

构造柱是设置在砖混结构墙体交接处的钢筋混凝土竖向构件。它与圈梁共同构成"弱框架"体系，约束墙体变形，是提高砌体结构抗震性能的关键措施。

- 箍筋 Φ6–8@200mm，端部加密 @100mm
- 混凝土 ≥ C20
- 马牙槎每步退 60mm，高 ≤ 300mm，先退后进

### 设置位置

根据《建筑抗震设计规范》GB 50011：

| 设置位置 | 具体要求 |
|----------|----------|
| 外墙四角 | 必须设置 |
| 纵横墙交接处 | 内外墙交接、纵横墙交接 |
| 大洞口两侧 | 洞口宽度 ≥ 2.1m 时 |
| 楼梯间四角 | 梯段平台四角各设一根 |
| 较长墙体中部 | 墙长超过层高 2 倍时中部增设 |

### 马牙槎

构造柱与砖墙连接处应砌成马牙槎。作用是增大构造柱与墙体的接触面积，形成可靠的剪力传递路径，防止地震时墙体与构造柱脱离。

沿墙高每 500mm 设 2Φ6 拉结钢筋，伸入墙内 ≥ 1m。

### 与圈梁的连接

构造柱纵筋应穿过圈梁。构造柱（竖）+ 圈梁（横）共同约束墙体，大幅提高砌体结构的整体性和延性。

## 保温隔热

| 气候区 | 传热系数 K [W/(m²·K)] |
|--------|----------------------|
| 严寒 A/B 区 | ≤ 0.25–0.35 |
| 寒冷 A/B 区 | ≤ 0.45–0.60 |
| 夏热冬冷区 | ≤ 0.80–1.20 |
| 夏热冬暖区 | ≤ 1.20–1.80 |
