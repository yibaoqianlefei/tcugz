# 台阶与坡道

把室外到门内看成连续路线：实铺或架空支承决定台阶怎样承重，坡道表面与基层决定怎样使用，而排水、变形和门口平台又约束所有局部选择。三类模型分别服务这些问题，不能从一个坡面外观推定无障碍满足。

## 入口高差与台阶组织

台阶与坡道把室内外或局部高差连接起来，既属于交通，也与入口排水、门扇及室外地面相关。台阶通常由踏步与平台组成，可单面、双面、三面进入或组合布置。形式应让进入方向清楚，避免使用者在门口突然遇到不易察觉的高差。局部小高差是否采用台阶、坡道或调整整体标高，应同时考虑使用人群和无障碍连续通路。

室外台阶的踏面、踏高和平台尺寸应按建筑用途、使用人数及适用要求确定。入口平台要容纳开门、停留、转向和必要的轮椅操作，不能只比较它是否比门宽。平台及面层需形成适宜排水坡向，通常应避免把水引向室内，但坡度又不能妨碍站立、轮椅操作和门扇开启。雨棚、线性排水与入口标高可组合解决问题。

## 台阶构造与不均匀变形

实铺台阶可由面层、结构或垫层、基层组成，架空台阶则需另有梁板等承重体系。面层在室外应适合湿滑、磨损、温度和可能的冻融环境，石材或砖的外观完好不代表其支承和粘结可靠。基层需稳定，垫层与面层需有适当承托、连接和分缝，边缘与踏口要能抵抗使用冲击。

冻胀地区应结合土质、水分和冻结条件采取适当基础、换填或排水措施，不能用一种固定换土深度替代场地设计。砖砌、混凝土和条石台阶具有不同受力与变形特征；条石若跨在地垄墙等支座上，还应按跨度而不是实铺块材理解其工作。

建筑主体与台阶可能有不同的沉降和温度变形。可以在合理设计下使二者分离并处理接缝，也可以把台阶纳入整体基础与结构；两种策略服务于不同条件，不能同时随意拼用。后做台阶能够改变施工阶段关系，却不保证以后没有差异变形。接缝要兼顾防水、清洁和通行，避免形成开裂、翘起及积水。

在混凝土台阶节点，从面层、混凝土、碎石垫层追到土基层；再到钢筋混凝土架空台阶节点，找踏步、斜梁和下部基础位置，比较踏步下方是否由土体连续承托。两个实例没有完整的勘察与结构配筋，不能由模型代替沉降、冻胀或梁板基础设计。

## 坡道的坡度、平台与防护

坡道由坡段和必要平台组成。轮椅坡道、普通人行坡道、搬运坡道与汽车坡道的对象和安全要求不同，不可把一种坡度套到全部用途。坡度 i=H/L，其中 H 是高差，L 是水平投影长度；确定允许坡度后，所需水平长度为 L=H/i，另加平台与转弯空间。高差增大、空间转折和使用者能力会进一步影响坡段分段和平台布置。

无障碍坡道应作为连续可达通路的一部分，检查净宽、坡度与横坡、单段提升、休息平台、门口操作、扶手和边缘防护。它不只是把台阶边上一条窄带抹成斜面。轮椅脚轮和推行需要顺畅过渡，表面应在预期干湿条件下防滑，挡轮等边缘措施应避免轮椅侧滑坠落，排水设施也不应夹住轮子或手杖。

坡道基层和结构同样需要承载、稳定与防裂，面层材料应与坡向、连接及室外耐久相配。坡脚与坡顶要防积水，连接室内时要协调防倒灌与无障碍。具体参数应依据项目适用的无障碍及建筑要求选取，普通坡道和无障碍轮椅坡道的适用条件不能混用。

坡道扶手节点可点选坡道和扶手，观察斜段与水平段的衔接。模型没有完整起终平台、边缘防护与门口量测，因此还需在平面补出到达、转向、门扇和排水位置，再从室外连续走到门内检查有无路线中断。

## 坡道面层与基层的两种实例

方砖坡道可分别点选方砖、结合层、混凝土层、土基层及砖缝；砂浆坡道则比较整体面层、结合层与下部承托。顺坡画一条水路，再沿端部检查铺装、接缝和积水位置。所配旧图的厚度、配比与标号是本例资料，不因位于坡道上就成为全部坡道的通用标准。

砂浆坡道原图有防滑条说明，但模型没有独立防滑条网格，只能点选面层整体后对照二维图。表面防滑要适应实际干湿与维护状态，也不能替代轮椅坡道的坡度、平台、净宽和扶手检查。无障碍体系要求可查[《建筑与市政工程无障碍通用规范》GB 55019—2021 住建部发布公告及附件](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2021/art_17339_762461.html)。

## 读图与自测

平面上从到达路线走到门内，检查平台、门扇和转向；剖面上核对坡段起终标高、水平长度、排水与净空；节点上追踪扶手及防护锚固。

2. 一段坡道的坡度较缓，是否就不需要平台和扶手等检查？
3. 台阶与建筑交接开裂，能否直接用砂浆填实？
4. 实铺与架空台阶的主要传力差异是什么？
5. 砂浆坡道原图标注了防滑条，为什么模型不能要求逐条点选？

参考答案：1. 可能存在门槛、占用平台或路线中断。2. 不能，只核坡度不构成完整设计。3. 应先判断沉降、冻胀及位移，填实可能再次开裂或约束原有活动接口。4. 前者经垫层传到土体，后者经梁板和下部支承跨越空间承载，不能混用基层概念。5. 原模型没有独立建模，应用面层整体与二维说明互证，并承认三维证据边界。
