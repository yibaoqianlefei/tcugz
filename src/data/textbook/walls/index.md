# 墙体概述

墙体既决定建筑空间的边界，也可能参与竖向承重和抵抗水平作用。一面墙能否开洞、怎样与楼板连接、外侧怎样防雨，必须先看它在结构体系中的身份，再看其材料与使用环境。本部分按作用、类型、砌体与隔墙、性能要求、细部和装修展开，建立从整面墙到连接节点的阅读顺序。

## 本章学习目标

学完本章，应能依据传力路径判断墙的角色，按不同维度描述墙体类型，解释砌体错缝和周边连接的作用，并在墙身剖面中追踪荷载、水分、热量与声音的路径。学习重点是说明构造措施为什么有效，而后把这些措施组织成可识读的节点。

本章始终使用同一个对象：一片带窗、与楼板和首层地面相接的外墙。每学一节就在这张剖面上增加一组信息，而不是重新收集互不相干的构造名称。最终应能交出一张有传力箭头、防排水线、保温边界和接口说明的墙身草图。

## 用一张剖面组织知识

![砌筑墙体水平防潮层与高差邻土侧竖向连接的位置示意，非施工详图](/images/learning/wall-paths.svg)

上图只用于定位墙身防潮层，不表示传力、洞口、保温或散水的完整构造。请另画带窗外墙草图，先画出楼板、墙和基础之间的传力箭头；在洞口上方辨认过梁，在墙体交接处辨认拉结和整体性措施。再画雨水从上口、窗台到散水的排离路线，以及土壤毛细水可能上升的位置。随后检查保温层是否在梁柱和洞口周围连续，最后标明饰面和密封缝如何收口。

同一构造往往影响多项性能：穿透保温层的连接件可能形成热桥，未封闭的管线孔可能同时影响隔声与防火，过硬的填缝可能因主体变形而开裂。因此不能把各项要求分别满足后就停止检查，还应检查它们在节点处是否相容。

读模型按三个动作进行：先在组装状态辨认相邻构件；有分解功能时再展开，用点选或独立展示确认遮挡处；最后回到草图，用一句因果解释代替材料清单。没有分解动画的布置模型用旋转和点选完成观察，不要求操作不存在的功能。需要完整图纸才能判断的跨度、支承和性能，应写进补查资料栏。

|学习阶段|要回答的问题|留下的证据|
|---|---|---|
|身份与类型|楼板由谁支承，这面墙分隔哪里？|支承路线、四维分类句|
|砌体与隔墙|块材或面板如何连接为稳定系统？|错缝、水平联系、竖向联系与顶部接口|
|性能与细部|水、热、声音会从哪里绕过主体？|连续边界及墙脚、洞口节点|
|饰面与维护|面层如何固定，缺陷从哪里开始？|基层到面层的层次和检查顺序|

> [!要点] 穿透保温层的连接件可能形成热桥，未封闭的管线孔可能同时影响隔声与防火，过硬的填缝可能因主体变形而开裂。各项要求分别满足并不等于整体合格，还要在节点处核对它们是否相容。

## 观察与自测

观察一栋熟悉的建筑，选择一片外墙和一片内墙，分别记录其位置、结构角色、材料线索、洞口和可见缺陷。图纸不全时，把推测和已知信息分开记录。

1. 为什么不能仅凭墙厚判断是否承重？
2. 墙面潮湿是否一定是防潮层失效？
3. 模型中没有显示窗框锚固，能否据此认定窗框不需要固定？
4. 请用本章的阅读顺序解释墙脚饰面起皮，不能只写“重新抹灰”。

参考答案：①承重取决于结构体系、支承与连接关系，墙厚只能提供线索。②潮湿还可能来自雨水渗漏、管线漏水或结露，应先追踪水源。③不能；局部模型的表达范围不等于完整构造，需要补查固定详图。④先确认墙脚和地面的关系，再查雨水、毛细水或结露来源，核对防潮连续性、基层状态与面层连接，最后选择相容的修复方法。
