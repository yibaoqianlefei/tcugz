# 墙体

墙体是建筑中沿竖向展开、形成空间边界的构件。一片墙可以支承楼板，可以保护室内免受风雨影响，也可以划分房间。墙的材料与厚度只是外在特征；理解墙体构造，应先判断它在结构体系和使用空间中的任务，再研究怎样连接、怎样阻断水热声的传播、怎样完成表面保护。

## 本章学习目标

学完本章，应能依据传力路径判断墙的角色，按不同维度描述墙体类型，解释砌体错缝和周边连接的作用，并在墙身剖面中追踪荷载、水分、热量与声音的路径。学习重点是说明构造措施为什么有效，而后把这些措施组织成可识读的节点。

4. [墙身细部构造](/lesson/basics/wall/wall-details.html)：集中学习墙脚防潮、勒脚、室外排水、洞口及整体性构造。
5. [隔墙](/lesson/basics/wall/wall-partition.html)：比较砌筑、轻骨架、条板系统，处理连接、变形与设备接口。

## 用一张剖面组织知识

以带窗外墙为例，先画出楼板、墙和基础之间的传力箭头；在洞口上方辨认过梁，在墙体交接处辨认拉结和整体性措施。再画雨水从上口、窗台到散水的排离路线，以及土壤毛细水可能上升的位置。随后检查保温层是否在梁柱和洞口周围连续，最后标明饰面和密封缝如何收口。

同一构造往往影响多项性能：穿透保温层的连接件可能形成热桥，未封闭的管线孔可能同时影响隔声与防火，过硬的填缝可能因主体变形而开裂。因此不能把各项要求分别满足后就停止检查，还应检查它们在节点处是否相容。

## 观察与自测

观察一栋熟悉的建筑，选择一片外墙和一片内墙，分别记录其位置、结构角色、材料线索、洞口和可见缺陷。图纸不全时，把推测和已知信息分开记录。

1. 为什么不能仅凭墙厚判断是否承重？
2. 墙面潮湿是否一定是防潮层失效？
3. 更换隔墙前应核对哪些资料？

**参考答案：**承重取决于结构体系、支承与连接关系，墙厚只能提供线索。潮湿还可能来自雨水渗漏、管线漏水或结露，应先追踪水源。更换隔墙应核对结构图、楼板承载条件、墙体稳定、声火湿要求及设备连接。
