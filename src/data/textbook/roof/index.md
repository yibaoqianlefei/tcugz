# 屋顶

屋顶是建筑最上层的围护结构，兼具承重、防水、保温、隔热功能。

## 屋顶的分类

按排水坡度可分为**平屋面**和**坡屋面**两大类。

| 类型 | 坡度 | 排水方式 |
|------|------|----------|
| 平屋面 | 2%-5% | 有组织排水/无组织排水 |
| 坡屋面 | ≥10% | 檐沟外排水/天沟内排水 |

## 平屋面构造层次

由上至下：保护层 → 防水层 → 找平层 → 保温层 → 隔气层 → 找坡层 → 结构层
