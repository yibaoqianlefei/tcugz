# 楼面构造布置

## 任务目标与前置知识

用一张布置图表达楼板、梁或承重墙的支承关系，并协调房间面层、洞口与标高。先阅读[楼地层概述](/lesson/basics/floor/floor-overview.html)、[钢筋混凝土楼板](/lesson/basics/floor/floor-rc-slab.html)与[地面构造组成](/lesson/basics/floor/floor-ground-composition.html)。

## 任务内容与条件

从方案中选取一个具有代表性的空间，绘制楼面结构布置示意，区分板、梁、墙柱与洞口，注明轴线、轴号、尺寸、构件编号和标高。可采用 1∶100 等适合表达的比例，并用局部剖面说明支承与面层标高。

## 工作步骤

1. 底图先画轴线、柱或承重墙、洞口和建筑边界，再标注方向及轴号。
2. 选择楼板体系，解释荷载由板到梁、柱或墙的传递方向。比较大空间、设备洞口和悬挑部位的支承条件。
3. 画主要构件布置和编号，明确梁板边界及预留洞口。使用一致的编号规则，并附图例；不要把历史构件代号当作唯一表达方式。
4. 协调结构面与建筑完成面标高，在湿区、阳台或需降低面层的部位另画简化剖面。面层高差应与防水、排水和通行条件相容。
5. 检查隔墙落位、设备管线、楼梯洞口与梁板是否冲突，再整理图面。

## 提交物

提交布置图、传力示意和一段层次说明。结构截面应注明来源或设计状态，不以经验估计代替结构计算。

## 自评与检查

自查板梁支承是否清楚，管线和洞口是否破坏主要受力部位，湿区面层与相邻房间标高是否协调。
