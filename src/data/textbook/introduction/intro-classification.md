# 建筑物的分类

## 按使用功能分类

按使用功能，可认识居住建筑、公共建筑以及工业、农业生产相关建筑等类型。住宅强调生活、私密与日常安全，公共建筑还需按具体使用者和活动组织空间，生产性建筑需适应工艺、设备与作业条件。同属一种大类的建筑，房间用途和风险也可能明显不同，不能仅凭大类名称确定全部构造要求。

## 按建造数量与规模认识

按建造数量与规模，可从大量建设的日常建筑和规模较大的复杂建筑两个角度理解标准化、适用性与专业协调。它们是帮助认识技术经济特点的教学分类，不意味着只有大型建筑才需要安全、耐久和环境性能。

## 按高度与层数认识

按高度、层数、结构体系或建造方式分类时，应明确采用哪项标准和哪种用途。消防分类、规划高度、建筑总高度与结构相关高度的计算对象及规则可能不同，屋顶设备用房、坡屋面和高差地面的处理不能脱离适用定义。旧住宅层数名称也不能直接替代当前消防分类或电梯设置要求。

## 按结构与围护体系分类

结构体系可按承重材料和传力方式认识，如承重砌体、混凝土框架、剪力墙、钢结构等；围护体系则可采用砌块、板材、幕墙等不同方式。承重体系与围护形式应分别说明，再检查两者如何连接及共同变形。

## 同一建筑的分类记录

比较框架与横墙承重布置时，先回答楼板由谁支承，再记录围护和房间使用条件。模型中的梁、柱和墙提供结构角色的观察线索，不能据此补写没有给出的建筑用途、人数、高度或性能等级。

|记录维度|可以说明的内容|还不能推出的结论|
|---|---|---|
|使用功能|学校教学、居住或生产等活动及分区|仅凭用途名称不能确定全部技术要求|
|结构材料与体系|混凝土梁柱骨架或承重砌体的传力组织|混凝土外观不能直接证明建筑耐火等级|
|围护材料与位置|砌块外墙、板材隔墙等组合|位于外侧不等于承担主体重力作用|
|项目边界|实际高度、规模、场地及资料口径|模型画面比例不能替代项目尺寸|

练习时给同一建筑写一句多维描述，然后逐词标明资料来源。某个维度未知时保留未知，继续到[构造组成](/lesson/introduction/intro-composition.html)检查作用关系；确定方案条件后，再在[构造方案说明](/lesson/practice/construction-brief.html)中组织选择依据。

## 分类练习与参考答案

1. 学校中的教学楼，在使用分类中属于哪一类？其钢筋混凝土框架结构属于哪个分类维度？
2. 为什么商住混合建筑需要分区域分析？
3. 已知建筑层数，能否直接判断它适用的所有构造要求？

参考答案：①通常属于民用建筑中的公共建筑；框架属于受力体系，钢筋混凝土属于结构材料。②不同区域的人员、火灾风险、声学和设备需求不同，交接处也有分隔与连接要求。③不能，还需用途、高度口径、场地、结构及相应标准的适用条件。
