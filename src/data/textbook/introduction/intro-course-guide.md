# 课程导读

## 构造设计贯穿设计过程

构造设计贯穿方案设计、初步设计和施工图设计。方案阶段已需判断结构、围护厚度、交通空间与排水等条件是否可行；深化阶段进一步落实材料、尺寸、节点和施工要求。建筑、结构与设备等专业应相互协调，构造并非只在方案确定后补画的细部。

## 基础与原理的学习顺序

本教材先从基础与地基认识建筑的支承，再学习墙体、门窗、楼地层、楼梯、屋顶和变形缝，建立从下部到上部、从构件到连接的认识。原理部分依次讨论保温、防水、隔热、隔声、防火和防潮，帮助把同一机理用于多个部位。阅读屋面时可回看防水和隔热，阅读墙脚时可回看防潮，阅读隔墙和楼板时可共同检查隔声与防火。

## 从作用路径到图纸表达

学习时应同时完成三件事：识别构造所解决的问题，追踪力、水、热、空气或声音的作用路径，画清层次与连接。仅记材料名称或图形外观，难以判断新材料、新系统和不同使用条件下的方案。现场观察与三维模型有助于认识空间关系，二维详图则应进一步落实尺寸、标高、材料和接口。

## 自测与参考答案

1. 为什么方案阶段就要考虑构造？
2. 学习一个防水节点时，除了材料名称还应记录什么？
3. 一种新板材可以替代整个外墙系统吗？

参考答案：①构件尺度、连接、使用性能和施工条件会影响空间与造型的可行性。②记录水源、排水方向、防水连续线、转角与穿透部位、固定方式和施工先后。③应先确认板材的作用及系统适用条件，再与支承、保温、防水、密封等部件共同设计。
