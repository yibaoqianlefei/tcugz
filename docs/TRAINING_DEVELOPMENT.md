# 作业训练初版开发与验证

日期：2026-10-02

## 交付范围

本地入口 `/#/games`，八种训练模式、17 道人工编排题目。各模式至少两题。

| 模式 | 初版内容 | 操作 |
| --- | --- | --- |
| 模型构件辨识 | 檐沟、箍筋、中间平台 | 转动模型、点选构件或字母 |
| 构件功能配对 | 檐口排水、楼梯组成 | 构件与功能配对，逐项反馈 |
| 构造层次排序 | 钢挂瓦条屋面完整层次、支承瓦材层次 | 拖动排序或上下移动按钮 |
| 图纸与模型对应 | 排水口、混凝土柱身 | 圈示图纸与三维构件对应 |
| 排水与传力路径 | 屋面至排水口、楼面板至柱 | 逐项点选、撤回、查看正确路径 |
| 情境方案判断 | 杯形与锥形独立基础 | 切换真实模型、选择方案与理由 |
| 构造错误诊断 | 缺少排水口、缺少檐沟 | 观察缺失模型，提交后恢复完整模型 |
| 三维装配补全 | 檐沟节点补全、错位修正 | 选择构件、预设位置放置、移除、替换 |

提供即时解析、提示、重试、续练和错题回顾。重复提交不累加尝试次数；重试或已查看提示不会增加首次独立答对数。

## 保持当前功能的实现方式

- 新增 `trainingStore`，使用独立 localStorage 键；不写入 `nodeStore`。
- 训练场景克隆原模型和材质，原几何只读共享。隐藏、选中、分开观察和装配位移都作用于私有场景。
- 训练 Canvas 使用按需渲染，不增加持续自动旋转循环。相邻字母标记避让，并用指示线关联构件。
- 原首页 Canvas 保持挂载，训练答题或重试不会触发首页模型重载。
- 新增训练子路由，右上角统一返回训练中心。训练目录位置有单独的会话存储，原课程和节点库返回路径保持不变。
- 模型未加载完成或加载失败时禁止提交；可重新加载模型，已作答内容保留。
- 作业训练首页说明更新为可进入训练中心；右侧窗口复用题库中的“找到檐沟”训练与真实檐沟模型。

## 内容审计结果

1. 旧 `organized-drainage.glb` 使用 `01`–`04` 网格名称，部分几何范围与现有天沟、雨水斗、落水管、雨水口说明不一致。未将这些网格用于训练判题，也未修改现有首页和节点页面。
2. 排水题使用 `eaves-gutter.glb`，其屋面顶、檐沟、檐沟分水、排水口均有明确名称，并与现有剖面图核对。简化排水路径截至排水口，不虚构模型中不存在的完整落水管和地面雨水口。
3. 原平屋面层次数据中存在说明与排序不一致，初版排序题使用钢挂瓦条屋面；题目明确是空间层次而非施工工序。
4. 每题绑定的真实模型路径和目标网格都有测试校验。基础方案题引用原独立基础变体配置。

## 初版边界

- 进度仅保存在当前浏览器，不是教师成绩系统，不支持账号同步和跨设备作业提交。
- 装配为固定方向、预设位置的教学练习，不是自由 CAD 装配，也不做碰撞或结构验算。
- 排水、荷载路径展示构件关系，不模拟实际水流或应力。
- 图纸圈示是构件的示意对应，不用于尺寸比例校核。

## 验证

- `npm run lint`、TypeScript 类型检查通过。
- 原有 `npm test` 13 组测试通过，涵盖模型来源、拆解、相机适配、菜单、旋转、节点定义和资产。
- `npm run test:training`：8 模式、17 题、错误/不完整答案、源场景隔离、装配重复更新、提示与重试计分、存储通过。
- `npm run test:training:browser`：八模式真实操作、答题与重试保持 Canvas、刷新续练、目录返回位置、模型加载失败重试通过。
- 浏览器检查 768、390、320px 无横向溢出。
- 新训练返回首页：原 Canvas 不重建、GLB 不重复请求、侧栏折叠状态和内容位置保留。
- `/tcugz/` 子目录打包构建及训练浏览器检查通过，模型和路由路径正确。返回位置检查先等待首页样式稳定，再按实际离开位置验证。
- 原首页模型和 UI 导航浏览器回归通过：课程定位/高度、侧栏恢复、节点列表返回位置、节点工作台高度与课程错误页重试。

## 后续顺序

先通过本地体验核对题目难度和操作，再扩充各模式题库。新增题目继续要求模型网格、图纸部位与判题答案一致。教师布置、收作业和跨设备记录作为独立后续阶段设计。

## 首页训练窗口升级

- 指定题目：`identify-gutter`，模型、目标构件、提示和答案来自同一题库。
- 右侧主要展示真实三维模型，提供转动、缩放、分开观察、A/B/C/D 点选、提示、提交和重试。
- 显示实际模式和题目数量，支持进入同一道训练、层次排序或三维装配。
- 首页试练状态独立，不写入训练成绩记录。首次展示第三板块才请求训练 GLB；切换板块、侧栏或返回首页均保持原 Canvas 和试练状态。
- 首页和训练页的匿名构件选项仅显示字母，减少重复文字。
- 训练模型共享组件样式独立提取，原训练工作台的响应式尺寸保留。
- 模型触摸操作不会触发首页轮播切换。正式首页和独立预览的 1440/390/320px、错误重试、状态保持检查通过。
