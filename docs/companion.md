# 构造伙伴

当前版本无需模型账号即可运行。悬浮伙伴在正式 SPA 页面中常驻，点击打开资料问答，拖动可停靠两侧。首页原“AI 拓展”入口以及 `/ai`、`/ai-extend` 打开伙伴介绍页；隐藏伙伴后可以从该入口唤回。

## 当前能力

- 根据当前首页展示节点、节点工作台选中构件、课程章节和案例主题查找站内资料。首页滚动到课程导航区时，当前内容会切换为对应板块。
- 回答附可打开的站内来源；选中构件使用对应卡片，保留未标注信息。
- 课程空正文会说明尚未提供，不生成补充教材；规范条款没有有效出处时不推断编号。
- 未提交训练使用现有提示，提交后使用现有解析。获得本题提示会记录 `hinted`，不会计为首次独立答对。
- 跨页保留本次会话，关闭不删除；刷新会重置聊天，不影响节点访问或训练存档。设置中可清空对话、恢复停靠、隐藏伙伴。
- 界面明确标注“站内资料”模式。该模式是检索与摘录，不能执行开放式生成，也不自动分析 GLB 或图像。

只覆盖当前 `/#/…` 正式页面；直接打开的静态课程 HTML 和封存旧 UI 没有注入伙伴。

## 运行与资料维护

```sh
npm run build:companion
npm run dev
```

`npm run build` 自动生成知识资料。修改节点卡片、课程或训练题后重新生成；开发服务运行中不会自动重建该 JSON。

生成器读取当前节点配置、单模型/多方案卡片、课程白名单正文、案例主题和训练提示。输出 `public/data/companion-knowledge.json`，当前为 469 条来源和 17 条训练帮助。训练帮助不含答案映射，但作答后解析是公开的：这是自主学习功能，不适用于安全考试。

## 后续接入真实 AI

当前没有创建后端、配置密钥或调用模型。前端已预留 `VITE_COMPANION_API_URL`，它只能是公开的问答接口地址。模型密钥必须保存在后端，不得使用 `VITE_*` 暴露。

接口契约：`POST` JSON 请求；响应为 JSON，暂不使用流式协议。客户端有停止与 25 秒超时处理。后端须提供 HTTPS、允许正式网站来源，并实际实现验证、限流、费用上限和凭据保护；CORS 不能代替这些措施。

请求包含：

```json
{
  "question": "解释选中构件",
  "context": {
    "kind": "node",
    "route": "/node/free-fall-ring-beam-eaves-01",
    "title": "自由落水檐口（圈梁带挑檐板）",
    "nodeId": "free-fall-ring-beam-eaves-01",
    "objectName": "防水层双向钢筋网"
  },
  "messages": []
}
```

后端不能相信客户端提供的文本事实或引用列表；应根据当前构建的同一知识资料重新检索，保持来源版本一致，并将资料视为数据而非指令。

响应示例：

```json
{
  "text": "基于当前构件卡片的解释……",
  "sourceIds": ["component:free-fall-ring-beam-eaves-01:防水层双向钢筋网"]
}
```

前端只接受本次检索范围内的引用 ID，展示由本地资料生成的链接。响应中的文本使用纯文本渲染，不执行 HTML 或任意模型动作。来源不合法或请求失败时，用户可以切换查看站内资料；配置地址不代表服务已验证接通。

训练问答即使配置了接口也继续使用确定的课程提示/解析，避免将完整答案对象发送给模型。后续若开发生成式训练教练，须单独验证提示与成绩规则。

```sh
npm run test:training
npm run build
```

浏览器回归默认针对本地 Vite 服务 `http://127.0.0.1:5173/`，使用隔离浏览器上下文，不触碰用户本机学习存档。截图与结果在忽略的 `tmp/companion-browser/`。

数据分析不再生成模拟问答或访问频次。旧记录继续保留，缺少来源标记的历史问答不进入新版问答分类；历史访问次数不反推，新的频次由实际访问事件累积。
