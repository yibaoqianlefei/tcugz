# 建筑案例升级：萨伏伊别墅

2026-10-02。本轮为本地开发，未部署至 GitHub Pages。

## 完成范围

- 首页第二张功能预览改为萨伏伊别墅三维教学模型。点击模型、空间标记或下方主题，联动高亮与简短说明。
- 构造主题为架空柱、水平长窗、屋顶露台。首页入口可直接进入选中的分析主题。
- 新增 `/#/curriculum/cases/villa-savoye?topic=roof` 等详情入口。主题写入路由查询参数，刷新与从课程/训练返回可恢复主题。
- 分析页包含观察要点、构造原则、三道主题理解自测，以及课程目录/正文和现有训练的关联入口。
- 关联训练是通用知识练习，页面明确说明其不是别墅原始节点的复原。自测不写入现有训练成绩。
- 案例目录增加可进入的完整项目卡片；原郓城三个开发中记录保留在折叠资料栏中，节点定义未删除。
- 详情页沿用右上角统一返回按钮，返回案例应用目录。无效案例地址提供目录入口。

## 模型与资料依据

采用本地代码生成的教学几何，无第三方 GLB 或贴图下载。保留白色上层体量、退入的细柱、连续窗带、底层曲面入口、开放露台、上层日光浴场、坡道与曲面挡风墙。

尺寸、柱网、坡道位置、框料及细部作了教学简化，不是测绘模型、施工图或工程验算模型。未添加无依据的配筋、排水节点或材料层次。模型及页面明确标注“教学示意模型”。

## 性能与状态

- 首次进入首页案例板块才创建案例 Canvas；离开板块或首页后保留该画布。
- 按需渲染，不增加持续旋转循环。像素比上限 1.5，阴影贴图 1024。
- 选中构件仅更新私有场景材质，不重建几何与相机。窗口和侧栏尺寸变化保持观察方向与缩放比例。
- 场景资源由组件独立持有，销毁时释放几何与材质；原节点及训练资源未修改。
- 模型拖动不触发首页横向轮播。WebGL 不可用时继续提供分析、主题与自测，并提供模型重试。
