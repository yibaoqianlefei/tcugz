# 全站右上角返回按钮位置审计

当前状态：下文为改进前快照。三项建议均已实施，开发与生产复查结果见[修订验证](修订验证.md)。

审计日期：2026-10-23。审计对象：本地工作区网站 http://127.0.0.1:5187/。

结论：常态页面中返回按钮均可见、可点击、无越界，但不同页面的定位基准不统一；短屏展开构造伙伴时出现实质遮挡；主站与独立教材页的按钮高度不一致。本轮仅生成审计脚本、量测数据和截图，产品代码保持本轮审计前状态。

## 范围与方法

- 逐页覆盖 164 个 SPA 地址：62 个教材文档、79 个节点地址、8 种训练模式、9 个其他栏目、2 个建筑案例、4 个错误状态页面；在 1440px 和 390px 下检查。
- 8 类代表页面在 2560、1920、1440、1366、1280、1279、1024、768、760、600、390、375、320px 下分别检查首屏及滚动后状态。
- 补查教材目录收起；1440×900、1440×768、1024×768、390×844、390×740、844×390 下，节点库、教材章节、节点交互三类页面展开构造伙伴的状态。
- 62 个独立教材 HTML 文档另在 1440px、390px 下检查。public/curriculum 与 public/lesson 的 61 对文档完全相同，墙体目录仅存在 CSS 相对路径调整，采用同一页眉布局。
- 总计 679 次位置及状态量测，未出现加载失败或页面脚本错误。检查包括按钮个数、坐标、右边距、垂直居中、品牌区域交叠、视口边界及点击点最上层元素。
- 浏览器：本机 Chrome 自动化响应式视口；不等同于手机真机 Safari、系统缩放或刘海屏验证。未对全部模型的渲染内容重新审计。

## 发现一：短屏时构造伙伴遮挡返回按钮

优先级：中。影响实际鼠标/触摸返回操作，应先处理。

在 18 个问答面板展开场景中，12 个场景的返回按钮点击点被面板覆盖。受影响窗口为 1440×768、1024×768、390×740、844×390；每种窗口均在节点库、教材章节、节点交互页复现。

桌面 768px 高度下，返回按钮顶部为 17.5px，高 40px；问答面板顶部为 24px，覆盖了按钮大部分区域。390×740 手机视口中，返回按钮顶部为 11.5px，问答面板顶部为 8px，按钮被完全挡住。命中测试实际落在 companion-panel-head，需先收起面板再点击返回。

原因：src/components/companion/companion.css:16–18 与 :89 根据底部位置和窗口高度确定面板高度，没有为顶部页眉预留足够空间；面板所在层级为 45，页眉为 30。问答面板为非模态 dialog，底层导航仍存在。

建议：根据实际页眉高度限制问答面板的顶部和最大高度，保留至少 8px 间隔，并在面板内部滚动。避免仅提高返回按钮层级，否则会把遮挡问题转移到问答面板自身的按钮。

证据：covered-1440x768-lesson.png、covered-390x740-library.png，以及 audit.json 中 stage=companion-open 的记录。

## 发现二：普通栏目与教材章节采用不同右对齐基准

优先级：中。影响宽屏页面切换的一致性。

下表为返回按钮右边缘距浏览器右侧的实际距离，单位 px：

| 视口宽度 | 节点库、节点页等普通页面 | 教材章节页 | 差值 |
| --- | ---: | ---: | ---: |
| 2560 | 614 | 24 | 590 |
| 1920 | 294 | 24 | 270 |
| 1440 | 67.67 | 24 | 43.67 |
| 1024 | 48.13 | 24 | 24.13 |
| 768 | 36.09 | 24 | 12.09 |
| 760 | 20 | 20 | 0 |
| 390 | 20 | 20 | 0 |
| 320 | 20 | 20 | 0 |

普通页面使用 src/styles/site-components.css:5 的居中容器，max-width 为 1500px，并叠加 --ui-gutter。教材章节则由 src/components/textbook/book-reader.css:7 取消最大宽度，固定左右内边距 24px，手机改为 20px。因此宽屏下从章节打开节点，会使按钮向左移动很大距离。教材目录页沿用普通页面规则，目录进入正文也会改变位置。

独立教材 HTML 还保留第三套文章页眉规则：例如 1440px 下独立隔声章节按钮距右 36px，嵌入主站的同一章节为 24px。

建议：统一顶部操作区的对齐基准。延续当前教材页视觉，可将所有页眉操作区设为桌面距右 24px、手机距右 20px；正文容器继续保留各自阅读宽度。主站、教材目录、独立文档使用同一规则。

证据：library-2560.png 与 lesson-2560.png；audit.json 中 stage=responsive、standalone 的记录。

## 发现三：主站与独立教材的按钮高度相差 4px

优先级：低。视觉和触控规格一致性改进。

- 主站页面测得按钮高度均为 40px：桌面顶部 17.5px，手机顶部 11.5px。
- 独立教材页面测得按钮高度均为 44px：桌面顶部 15.5px，手机顶部 9.5px。
- 全站已有 --ui-control-height:44px，但 .site-back-link 在 src/styles/site-components.css:20、:92 单独使用 40px。

建议：返回按钮也使用统一的 44px 控件高度，保留现有字体、箭头、蓝色和圆角，垂直位置随页眉自动居中。40px 在本次检查中仍可正常点击，此项不列为功能阻断。

## 已通过的项目

- 所有常态页面均只有一个可见的右上角返回按钮；无按钮越界、品牌交叠或点击点被普通页面内容遮挡。
- 104 次滚动状态检查中，页眉顶部始终为 0px；按钮继续随粘性页眉保持位置。
- 教材侧栏展开和收起时，返回按钮右边距均为 24px。
- 320px 手机宽度下，实测最长代表文案“返回首页 · 构造原理”宽约 173.91px，无溢出。
- 所有页面的按钮垂直居中误差均为 0.5px，来自页眉底部 1px 边框。
- 首页是顶层学习入口，当前没有右上角返回按钮；审计未将其记为缺失。

## 建议处理顺序

1. 修复短屏下问答面板遮挡导航。
2. 统一页眉右边距，优先覆盖章节、节点、目录之间的切换。
3. 统一 44px 高度及独立教材页眉样式。
