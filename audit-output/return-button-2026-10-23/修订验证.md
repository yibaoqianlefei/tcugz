# 返回按钮改进与复查

日期：2026-10-23。

原审计提出的三项改进已完成：

1. 主站栏目、节点页、教材目录、教材正文及独立教材 HTML 的返回按钮统一为桌面距视口右侧 24px、760px 及以下距右 20px。
2. 返回按钮统一使用 44px 控件高度，随页眉垂直居中。沿用原有蓝色、箭头、字体及圆角。
3. 构造伙伴问答面板顶部距页眉至少 8px；可用高度随窗口和节点页停靠位置计算。短屏时面板内部可滚动，标题栏保持可见，并提供输入所需空间。

正文的阅读宽度、品牌与正文的左侧对齐规则保持原样，顶部操作区的右边距独立使用 --ui-topbar-gutter。
