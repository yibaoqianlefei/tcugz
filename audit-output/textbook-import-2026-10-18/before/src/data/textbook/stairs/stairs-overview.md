# 楼梯的基本概念及设计要求

楼梯通过踏步和平台连接不同标高的空间，是日常垂直交通的重要设施，也可能承担建筑疏散。学习楼梯不能只计算“能否放进一个房间”，还应把位置、人数、通行、防火防烟、无障碍衔接与构造连接共同考虑。

## 组成与分类

梯段由连续踏步组成；楼层平台与楼层地面衔接；中间平台供休息和转向；梯井是梯段之间形成的空间。栏杆或栏板用于临空防护，扶手为行走提供抓握。两者功能相关，但不能相互替代。

按梯段数量和转向，可识别直跑、折返、折角等形式；剪刀楼梯、螺旋楼梯、弧形楼梯则具有不同空间组织。形式选择需检查其用途与适用条件，不能因为平面紧凑就认定适合作为疏散楼梯。可打开[楼梯组成模型](/#/node/stair-composition-01)辨别梯段、中间平台与楼层平台。

楼梯间还可根据空间围护与防烟组织区分开敞、封闭、防烟等类型。封闭楼梯间不是仅加一道普通门，防烟楼梯间也不能只凭窗洞判断；防火分隔、门、前室和防烟设施需组成完整系统，详见[建筑防火](/lesson/principles/fire.html)。

## 五组设计参数

**踏高与踏面宽**分别用 h、b 表示。梯段坡度按升高与水平距离理解，为 h/b。步距经验关系可以帮助比较舒适程度，但经验式不能代替特定建筑用途的限值。儿童、老年人以及高密度人流，对尺度和防滑有不同要求。

**梯段净宽**应按适用规定的测量边界确定。轴线开间、两墙之间尺寸与通行净宽不是同一个量；扶手和突出物可能占用有效空间。还应区分日常通行需要、规定的最小净宽及按疏散人数计算的宽度。

**平台**用于转向与衔接，需容纳门开启及实际通行。平台边缘、门扇和梯段不能互相侵占所需空间；搬运、轮椅路线和消防要求也应纳入相应设计。

**防护与扶手**需考虑临空风险、可踏面、儿童攀爬和连续抓握。高度从哪个基准测量、间距是否安全、扶手终端怎样处理，都应在图上说明。具体值应按用途与适用标准核对。

**通行净空**从通行完成面量至上方最低障碍物。平台板、平台梁、上层梯段、设备及装修都可能成为控制点，不能只用中间平台标高减去地面标高。

## 级数与投影长度

设层高为 H，全层踢面总数为 N，则选定整数 N 后踏高 h=H/N。若采用等跑双跑楼梯，每跑踢面数 n=N/2；按本节示例的平台衔接方式，每跑独立踏面数为 n−1，水平投影长度 L=(n−1)b。不同首末步构造应根据实际剖面核对，不能无条件套用计数。

本节只作几何演算，**假设**层高 H=2800mm、选定踏高 h=175mm、踏面宽 b=260mm，采用等跑双跑。于是 N=2800/175=16，是全层总踢面数；每跑 n=8，升高1400mm，每跑水平投影 L=7×260=1820mm。这些假设不是住宅、幼儿园或其他建筑的统一合规参数。

若再假设中间平台深1250mm、楼层平台深1300mm，则上述净尺寸链为1820+1250+1300=4370mm。此值只表示示例中相应空间的合计，仍未包含墙体、轴线关系、门、装修和不同支座节点的影响，不能直接写成楼梯间轴线进深。

## 首层入口与净空复核

中间平台下设入口时，应在剖面中找到梁底等最低点。若仅为演算，假设平台顶比入口完成面高2250mm，梁底低于平台顶300mm，则净空为1950mm。它是否满足要求，需按实际用途核对适用规定，而不能把平台顶2250mm当作通行净高。

增加第一跑级数可抬高中间平台，但会改变另一跑的级数、投影长度及平台位置；局部降低入口地面则会改变室内外高差、排水与可达路线。任何调整都要重画平面和剖面，重新核对门、平台与踏步。可观察[首层长短跑入口模型](/#/node/bottom-landing-entrance-01)理解这一几何关系。

## 从方案到图纸

设计先明确用途、层高、位置、人流、疏散与无障碍衔接，再选择形式及踏步；随后计算级数并分配梯段，检查平面尺寸链；用剖面复核净空与标高，最后协调结构、装修和细部。尺寸不满足时回到前面的选择进行调整，不应随意把余量塞进某一级踏步。

平面需表达轴线、墙体、各层踏步、平台、上下行方向、门、梯井及剖切位置。底层、中间层、顶层的可见梯段不同，不能复制同一平面只修改标高。剖面需与剖切方向一致，标出室内外完成面、楼层和平台标高、踢面数与踏高、净空控制点。结构与装修还需共同保证首末级完成后踏高协调。

结构方案见[钢筋混凝土楼梯](/lesson/basics/stairs/stairs-rc-structure.html)，踏口与栏杆连接见[楼梯细部](/lesson/basics/stairs/stairs-details.html)，入口可达路线见[台阶与坡道](/lesson/basics/stairs/stairs-steps-ramps.html)。

## 自测

1. 示例中全层16级，为什么每跑投影采用7个踏面宽？
2. 墙间尺寸足够，是否说明梯段净宽一定满足疏散要求？
3. 把第一跑从8级改为更多级，为什么要重新画第二跑？
4. 平台标高能否直接代表平台下净空？

**参考答案：**1. 每跑8个踢面，按示例衔接方式有7个独立踏面。2. 不能，还需扣除相应占用并核对测量边界、人数与用途。3. 层高总级数固定时，另一跑级数和两跑平面关系改变。4. 不能，应量到梁底等最低障碍物。
