# 建筑物的构造组成

## 从整体看建筑

建筑为活动提供空间，并通过承载和围护系统保持空间形态与环境条件。建筑各部分往往承担多项任务：承重外墙既传递荷载，又阻挡雨水；楼板既支承活动，又分隔上下空间。因此，分析构造时要同时看受力、围护、交通和连接关系。

## 两条典型传力路径

承重墙体系的典型竖向传力路径是“楼板或屋盖—承重墙—基础—地基”。框架体系则是“楼板—梁—柱—基础—地基”。这两条路线帮助认识基本受力组织，建筑还可以采用剪力墙、框架与剪力墙组合等其他体系。

基础是建筑构件，地基是支承基础的岩土体。基础把其所承受的作用传给地基，地基的承载和变形反过来影响建筑。传力路径应连续，连接应能传递相应作用。水平作用还需要通过楼屋盖与抗侧力构件等形成完整路径，不能只画竖向箭头。

框架中的填充墙主要承担围护或分隔任务，但仍承受自重及相应侧向作用，并与主体结构相互影响。是否承重应结合结构图与设计说明判断，不能通过墙体材料或外观自行判断。

## 六类基本构件

| 构件类别 | 主要任务 | 阅读构造时关注 |
| --- | --- | --- |
| 基础 | 连接上部结构与地基，传递作用 | 基底、持力层、连接及耐久保护 |
| 墙或柱 | 墙可承重、围护与分隔；柱主要承担结构作用 | 受力角色、洞口、拉结和层间连接 |
| 楼地层 | 提供活动面，楼板分隔楼层并参与结构协同 | 结构、面层、防水、保温和隔声 |
| 屋顶 | 顶部承载与围护 | 排水、防水、保温和边缘节点 |
| 楼梯 | 联系高差空间并承担通行作用 | 梯段、平台、支承、栏杆和安全通行 |
| 门窗 | 联系或分隔空间，提供通行、采光和通风 | 框扇、开启、固定、密封和维护 |

楼地层中，支承在梁墙等构件上的楼板与支承于地基上的地坪有不同传力路径。屋顶是整个顶部构造，屋面则强调其外侧防护与排水部分。电梯、设备系统、阳台、雨篷、台阶和坡道等可根据任务另行分析；饰面装修依附于相应部位，承担保护、改善性能和美化作用。

## 三种体系与四种层次

六类构件是按建筑部位组织学习。按功能又可以认识三种体系：承载体系保持支承与稳定；围护体系调节室内外环境，包含相应装修防护；交通与设备体系组织人、物、能量和信息的流动。这是另一种分类角度，同一构件可以参与多个体系。

一个具体构造还可以从四种层次分析：结构层传递作用；性能或设备层实现保温、防水、隔声及设备布置；连接层固定和协调部品；饰面层形成最终表面并提供保护。这是读节点的分析框架，不要求每个构造恰好有四个实体层。有些层兼有多项功能，有些功能由多个层共同实现，防水层的位置也需根据构造系统确定。

## 读一个剖面的顺序

先找楼板、墙柱和基础，画出主要传力箭头；再找室内外边界，追踪保温、防水等性能线；最后检查边界开口、交接和穿透部位。用这一顺序读外窗节点，可以同时发现洞口支承、框墙固定、窗台排水与保温连接，而不只辨认表面材料。

2. 六类构件与三种体系是否相互矛盾？
3. 四种构造层次是否意味着所有节点必须画出四层？
