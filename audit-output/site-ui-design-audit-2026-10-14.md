# 全站 UI 审计与共同设计逻辑

审计日期：2026-10-14。对象：当前本地网站及实际生效的路由、React 组件、静态课程模板和样式。

**结论：网站已有共同的颜色倾向，但尚未形成完整的共同 UI 规则。建议以目前章节封面的「暖白底、深蓝文字、红蓝几何、编辑式排版、清晰细线」为品牌基础，为目录、阅读、资源浏览和操作工作台分别建立模板。共同规则需要覆盖布局、字体、控件和状态，才能延续到所有页面。**

本轮交付为审计和设计规范，未修改正式页面、教学内容或交互功能。下面的目标值是项目设计建议；「实测」部分来自当前页面。二者分别标明。

## 2. 应当保留的共同基础

1. 暖白 `#f8f8f5` 和深蓝 `#1c2544` 已贯穿大多数页面，适合作为整个教材的底色和主文字色。
2. Logo、英文眉题、中文标题、细分隔线已经具有辨识度，可以继续发展为统一的页头语言。
3. 构造基础七个封面已形成同一系列。六个抽象封面采用红蓝色块及闭合轮廓；墙体保留现有模型图。七个封面的装饰轮廓源线宽均为 2.4。
4. 正文的本节目录、章节导航，以及节点页的图纸／模型／构件知识关系，符合不同学习任务，应保留这些信息结构。
5. 训练已有禁用、提交、提示等状态，伙伴已有上下文和来源区域；统一工作应覆盖这些状态，保持已有学习流程。

已确认的造型约束继续有效：抽象图形首先服务构图和美观；闭合的无填充轮廓可以用实线或虚线；楼地层当前的顺时针三角形与长椭圆比例、屋顶放大的正方形及粗实线轮廓均作为现有设计资产保留。章节封面以外，节点、案例、训练中的模型承担学习内容功能，仍应保留在相应任务区。

## 3. 当前主要问题

### P1-01：页面没有共同的对齐基线

1440px 宽度下的实测值：

| 页面 | 页头／标题内容左缘 | 正文或主体内容左缘 | 观察 |
| --- | ---: | ---: | --- |
| 构造基础封面 | 67.7px | 67.7px，卡片文字再内缩 24px | 可作为宽页面的对齐参照 |
| 普通课程目录、课程正文 | 72px | 72px；文章文字另有 43px 内距 | 与封面接近，但由另一套参数定义 |
| 构造节点库 | 184px | 184px | 与章节切换时明显收窄 |
| 案例目录与详情 | 184px | 152px | 同一页标题与主体相差 32px |
| 训练目录 | 184px | 160px | 同一页相差 24px |
| 构造伙伴介绍 | 184px | 210px | 同一页反向再缩进 26px |
| 训练工作台 | 40px | 40px | 宽度有功能依据，外围导航基线仍未对应 |

原因：`src/index.css:162` 已有 `.site-container`，但 `SectionPageHeader.tsx:2`、`LibraryPage.tsx:23` 等仍使用 `max-w-6xl`；案例主体为 1200px，伙伴主体为 1100px，工作台又另设宽度。

**处理规则：先统一「外层容器和页头左缘」，再为阅读栏、模型区等内层设宽度。每一种缩进必须对应明确的层级。** 首页桌面侧栏可保留，但主内容仍使用相同的内距和字级规则。

### P1-02：相同信息层级存在三套目录卡片

| 当前形式 | 出现位置 | 不一致之处 |
| --- | --- | --- |
| 带背景弧线、右上角「查看章节／可阅读」胶囊 | 首页课程入口 | 装饰较密集，状态多数只重复入口属性 |
| 白底完整方框、胶囊「可阅读」、标题上方大空白 | 绪论、原理、实践三个目录 | 与基础章节的编辑式网格脱节 |
| 无底色的编号细线网格 | 七个基础封面 | 更接近目前确定的风格，但墙体与其他六章细节不同 |

墙体的编号区高 64px，其余六章桌面为 36px；墙体还保留「可阅读」独立行。手机 390px 下，墙体第一张卡片标题出现在文档 y≈908px，楼地层约为 902px。首屏未出现卡片标题属于信息到达效率的优化项，不等同于显示故障；墙体还缺少其他六章已有的「浏览章节」锚点。

源码位置：`previews/homepage-v1.html`、`scripts/build-curriculum-preview.mjs:59`、`scripts/templates/wall-directory.html:49`、`public/lesson/wall-directory.css:51`、`public/lesson/module-directory.css:23`。

**处理规则：课程入口统一编号、标题、摘要和网格关系；状态仅在确有差异时出现。首页可以更紧凑，目录页可以更舒展，信息顺序应一致。**

### P1-03：颜色和控件来自多处独立定义

- 全局主色为 `#5b6dad`、激活色为 `#43558e`；章节使用 `#43558e`，墙体还有 `#43588d`，伙伴另有 `#43588f` 和自己的文字色。
- 伙伴使用 `system-ui / Microsoft YaHei` 字体栈，其他主要页面以 `Noto Sans SC / PingFang SC / Microsoft YaHei` 开始。此处确认的是 CSS 配置差异，未把字体栈当作实际安装字体的证明。
- 当前内容卡片有直角、8px、10px、12px 等圆角；模型工具栏用 16px，伙伴面板用 22px。浮层采用一定圆角和阴影有功能依据，但全站尚无对应的层级规则。
- 同为主要操作，首页、全局小按钮、训练提交、伙伴入口分别定义颜色、字号和高度。

这些差异不需要全部压成一个数值。应先定义「主要操作、次要操作、工具按钮、内容卡片、浮层」五种角色，再让所有页面按角色取值。

源码位置：`src/index.css:5`、`:14`、`:111`、`:116`；`src/components/companion/companion.css:1`、`:15`；`src/pages/training.css:13`、`:37`；`src/components/viewer/ControlBar.tsx:37`。

### P1-04：弱文字与移动浮动入口需要共同规则

按当前颜色计算：

| 文字／背景 | 对比度 | 解释 |
| --- | ---: | --- |
| 墙体弱文字 `#77839a` / `#f8f8f5` | 3.59:1 | 用于正常小字时低于 4.5:1 的目标，例如面包屑 |
| 其他六章弱文字 `#63708a` / `#f8f8f5` | 4.68:1 | 可作为统一弱文字候选 |
| 正文 `#58637d` / `#f8f8f5` | 5.65:1 | 有较好的可读性余量 |
| 白字 / 主题蓝 `#43558e` | 7.17:1 | 适合主要按钮 |
| 装饰红 `#e34b36` / `#f8f8f5` | 3.71:1 | 适合作为色块；普通小字应另设深色语义红 |

伙伴快捷提问和案例视图按钮实测为 11px 文字、高约 30.5／32.5px；节点布局预设为 11px、高约 24.5px。它们并非仅凭尺寸即可判定不合规，但在教学场景中显得偏细小。手机截图还显示伙伴浮动入口覆盖了训练说明、案例边缘和知识列表中的部分文字，需定义停靠避让。

**处理规则：必读说明和常用控件文字提升到 13–14px；移动主要操作目标建议 44px。伙伴入口应有可停靠安全区或收合规则，并检查内容和关键按钮是否被覆盖。**

WCAG 2.2 的普通文字对比度基线是 4.5:1，大字为 3:1；点击目标的 24×24 CSS px 条款包含间距、行内文本等例外。本报告将 44px 作为本项目的移动设计建议，没有把它误写成所有控件的强制合规线。参见 [W3C 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[W3C 点击目标说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)。

### P2-01：正文更接近通用文档容器，阅读层级还可加强

54 篇正文当前共享样式，1440px 下文章框宽约 1001px，减去边框和内距后文本区约 913px；正文与目录外围多次叠加白框、浅蓝底和分隔线。它们能阅读，但与封面较克制的编辑式风格仍有距离。

建议阅读文本区控制在 680–800px 的范围，按实际中文长度和图表校核；保留独立的图表宽区。章节大标题、正文各级标题、表格、提示、自测、上一节／下一节分别使用统一组件。这里的栏宽是设计判断，不是可访问性标准的硬性数值。

### P2-02：响应式和导航行为没有共同契约

- 手机普通课程页、React 子页顶栏高 53px；章节封面高 62px。手机正文边距为 20px，React 页头 24px，案例主体 18px，训练工作台 16px。
- React 子页顶栏是 sticky；静态课程顶栏随文档滚动。长页面的返回行为体验不同。
- 墙体在 701→700px 时，图形宽度从约 313px 跳到 550px，放大来自布局切换；应按封面系列统一控制图形尺寸，而非只检查是否溢出。
- 入口名称还有「AI 拓展／构造伙伴」「作业训练／训练中心」等表述差异，应该建立页面名称与返回文案表。

**处理规则：统一手机基础边距和顶栏高度，组件根据内容需要折叠；在断点两侧检查视觉连续性。工作台可以保留局部滚动和页签，目录和阅读页使用一致的返回规则。**

### P2-03：支持页和状态页还未采用统一信息密度

资源页是图标折叠卡，伙伴介绍同时使用通用大页头与另一个大标题，学习数据采用仪表盘卡片，工具箱和贡献节点使用空状态。这些页面都可归入支持页面系统：统一外层页头、说明、主体起点与按钮层级，保留各自的内容表达。

空状态应说明当前情况并提供一个明确下一步；加载和失败状态共享字体、占位范围和重试按钮。避免在标题区、主体区重复相同说明。

## 4. 建议采用的全站设计规范

### 4.1 共同视觉定位

**清晰、克制、有建筑教材的编辑感。** 大标题和留白负责层级，红蓝图形负责封面辨识，细网格负责内容组织，工作区用清楚的功能控件完成操作。

共同设计分为三层：

| 层级 | 应统一的内容 | 允许变化的内容 |
| --- | --- | --- |
| 基础令牌 | 色彩、字体、间距、线宽、圆角、焦点、动效 | 按已定义的角色选取不同值 |
| 组件 | 页头、面包屑、返回、卡片、按钮、页签、状态、折叠区 | 数量、内容和组合方式 |
| 页面模板 | 容器基线、信息顺序、主次关系、响应式行为 | 封面构图、阅读栏、模型布局等任务差异 |

### 4.2 颜色、线条与材质

| 角色 | 建议值 | 使用方式 |
| --- | --- | --- |
| 页面底色 | `#f8f8f5` | 全站主要画布 |
| 内容表面 | `#ffffff` | 必须分离的内容区、输入区 |
| 浅色功能区 | `#eef1f8` | 目录、工具分区、选中背景，避免整页堆叠 |
| 主文字 | `#1c2544` | 标题、重要信息 |
| 正文 | `#434b63` | 连续阅读和说明 |
| 弱文字 | `#63708a` | 元数据、辅助信息；需结合实际背景验证 |
| 主题蓝 | `#43558e` | 链接、主要操作、选中状态、封面色块 |
| 深蓝 | `#2e3d71` | 主要操作 hover 等深一层状态 |
| 装饰红 | `#e34b36` | 封面色块、少量品牌强调 |
| 细分隔线 | `#dce1e9` | 网格和区域边界；不能单独承担关键状态识别 |
| 反馈色 | 单独定义 success / warning / danger 的前景与浅背景配对 | 与图标、文字共同说明状态；不直接把装饰红当小字号错误文字 |

- 装饰轮廓：统一 2.4 个 SVG 用户单位，沿用当前 600×460 画布并随图缩放；路径闭合、无填充。实线或虚线按构图选择，虚线的路径也必须闭合。
- 界面分隔线：1px；图标通常 1.5–2px；键盘焦点 2px 且有外偏移。三者分别承担不同作用。
- 内容网格和课程目录：直角、平面；按钮和输入框：6–8px；工具浮层：12–16px，允许一档轻阴影。伙伴面板如保留更柔和的圆角，应作为有名称的浮层变体，不能独立发展另一套颜色和字体。
- 图形装饰集中在封面与入口的留白区；阅读正文、模型视口与题目操作区保持安静。

### 4.3 栅格、间距与字体

| 项目 | 建议规则 |
| --- | --- |
| 宽页面外容器 | 最大 1500px，包含内距；桌面内距沿用章节 `clamp(24px, 4.7vw, 84px)`；手机 20px |
| 页头对齐 | Logo 区、眉题、标题、首个主内容模块遵循同一外层容器；阅读栏和工具栏的局部内缩有明确角色 |
| 间距标尺 | 4、8、12、16、24、32、48、64、80px；段落、组件、模块分别使用不同档位 |
| 封面标题 | 桌面约 80–124px，手机约 54–72px；长标题单独按字数适配；保留现有章节已经调好的构图 |
| 列表／支持页标题 | 桌面 48–82px，手机 40–48px |
| 正文页标题 | 桌面 40–64px，手机 32–42px；不占用过多阅读起始空间 |
| 工作台标题 | 24–36px；节点页以紧凑标题表达当前位置，同时补足语义层级 |
| 区块标题 | 24–32px；卡片标题 18–22px |
| 正文 | 16px、行高 1.8–1.9；手机长文保持 15–16px；辅助说明与常用控件 13–14px |
| 字体 | 全站同一中文无衬线字体栈；英文眉题通过字号与字距区分，不另引入不相关字体 |

以上字级是不同语义角色的范围，实施时应收敛成明确 token，避免逐页使用任意 `clamp()`。标题换行以完整词组和构图为依据，不能为了统一字号而挤压长标题。

采用统一间距、比例和组件尺度的依据可参考 [Carbon 的栅格与尺寸规则](https://www.carbondesignsystem.com/building-blocks/foundations/2x-grid/overview)。具体的 1500px、4.7vw 和本表字级是针对当前网站的建议，并非照搬 Carbon 的参数。

### 4.4 按钮和状态

| 组件角色 | 共同规则 |
| --- | --- |
| 主要按钮 | 主题蓝底白字；常规高 44px；一个任务区突出一个主要操作 |
| 次要按钮 | 透明或浅色底、1px 边框；与主要按钮使用相同字体、内距和圆角 |
| 工具按钮 | 桌面视觉尺寸可为 32–36px；移动扩大有效点击范围；图标按钮具备明确标签 |
| 文本链接 | 蓝色；正文链接常驻下划线；导航及卡片链接保持明确 hover / focus |
| 选中状态 | 主题蓝边或底色，加文字、标记或 `aria-pressed` / `aria-selected` 表达 |
| 禁用状态 | 统一浅色前景／背景；需要说明原因的场景保留文字；禁用目标不伪装成正常按钮 |
| 错误／成功／提示 | 文字＋图标＋颜色，不能只靠颜色；反馈位置尽量保持稳定 |
| 键盘焦点 | 全站共同焦点样式；可见、无裁切，并与 hover 区分 |
| 动效 | 主要采用 160–200ms 的颜色和边框变化；浮层可适度过渡；尊重 reduced-motion |

卡片采用固定的信息顺序，但根据任务分为课程目录、资源预览、练习入口三种组件。统一编号、标题和说明的层级，不强迫所有卡片拥有相同高度或图片比例。节点图纸和模型缩略图使用 `contain`，真实建筑封面按内容选取比例，避免裁掉教学标注。

## 6. 实施顺序与源码边界

**第一批：共同基础。** 整理颜色、字体、间距和状态 token；统一容器、页头、返回和按钮。先用一个普通目录、一个正文、节点库和一个工作台校准，确认同一角色的参数可复用，再铺开。

**第二批：课程与目录。** 统一首页课程卡、三个普通目录、墙体及六章卡片；正文模板一次更新覆盖 54 篇。对既有封面只处理共同规则，不重新生成用户已经调整过的造型。

**第三批：功能页。** 节点、案例、训练、伙伴、资源、数据使用共用控件和状态，完成移动避让及局部布局校核。

| 源码层 | 需要承担的职责 |
| --- | --- |
| 建议新增单一令牌源，如 `src/styles/site-tokens.css` | 唯一编写颜色、字体、间距和角色值；静态课程构建复制同一源文件，避免多处手动同步 |
| `src/index.css` | Tailwind 语义映射、React 共用布局和交互状态；清理已无角色依据的旧卡片样式 |
| `src/components/SectionPageHeader.tsx`、`AppLayout.tsx` | 共用页头与容器、返回信息、全局入口 |
| `scripts/build-curriculum-preview.mjs` | 普通目录和正文的结构组件；共同课程元数据 |
| `scripts/lib/module-directory.mjs`、`scripts/templates/wall-directory.html` | 封面骨架与课程卡；图形作为独立配置保留 |
| `public/lesson/module-directory.css`、`wall-directory.css`、`curriculum.css` 的实际构建来源 | 引用共同令牌并保留页面族规则；需要沿构建流程定位源文件，不能只改生成结果 |
| `src/components/viewer/ControlBar.tsx` 及功能页 CSS | 将已有功能组件映射到统一按钮、页签、状态和浮层角色 |
| `DataAnalysis.tsx` 等图表 | 从同源设计参数读取图表色；避免靠注释要求人工同步色值 |

课程通过 iframe 展示，父页面的 CSS 变量不会自动穿过文档边界。这是当前两套样式容易分化的原因之一。令牌必须显式进入 React 和静态文档两侧。共同参数采用单一来源的做法可参考 [Design Tokens Community Group 格式文档](https://www.designtokens.org/tr/drafts/format/)。

若统一为滚动时固定的全站顶栏，建议由外层应用管理嵌入课程时的共同页头，同时保留静态文档独立访问时的页头；不要仅在一个被拉伸至全文高度的 iframe 内加 `position: sticky` 就认为已与父窗口行为一致。实施时必须保留课程的选中文本上下文、链接拦截、文内锚点定位与高度同步。

## 7. 后续改造验收清单

- 同一页面的页头与主体按角色对齐；跨页面外容器一致；允许的阅读栏、侧栏内缩有记录。
- 64 个课程路径继续可达；目录题数和标题不丢失；正文锚点、上一节／下一节和返回路径正常。
- 七个封面维持现有图形；六个抽象封面不加入模型图；装饰轮廓保持闭合、无填充，保留既有实／虚线区别。
- 1440、1024、768、390、320px 无非预期横向溢出，并检查 1050、760、700、600 等现存断点两侧；避免只凭零溢出判断视觉合理。
- 文字对比度按实际前景／背景配对检查；完成 hover、focus、selected、disabled、loading、error、empty 的样式检查。
- 桌面节点三栏、平板图纸面板、手机三个页签和多方案选择保持可用；模型完全加载后再判断构图。
- 八种训练模式分别检查选项、配对、排序和装配的控件；不改变答案、计分、保存和来源说明。
- 手机伙伴入口及面板不覆盖关键操作或必读内容；问答面板可关闭并恢复焦点。
- 保持 reduced-motion、键盘操作、真实内容图纸的完整展示；错误和空状态有明确下一步。

**实施完成的判断应是：进入任何页面，都能认出同一个教材的颜色、排版和操作方式；进入不同学习任务，又能立刻找到该任务的主要内容。**
