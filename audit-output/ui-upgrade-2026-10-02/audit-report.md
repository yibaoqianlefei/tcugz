## 需要修复的问题

### 1. [P2] 直接打开首页板块链接会落到错误位置

- 复现：新浏览器页面打开 `/#/?section=modules`。
- 实测：滚动位置为 1782px，但构造基础板块顶边位于视口上方 445px，未对齐目标板块。
- 原因：`LearningHomePage.tsx:59` 在布局阶段读取板块位置；外部首页样式在 `70–71` 行加载，首次进入时读取位置与样式生效的顺序没有保障。
- 影响：分享板块链接、直接打开课程返回地址时，用户看到的位置不稳定。
- 建议：等待首页样式就绪后完成首次定位，并让恢复已有页面位置与首次定位使用明确的触发条件。

### 2. [P2] 长课程切换到短课程后保留大量空白

- 复现：墙体设计要求 → 章节导航中的“墙体在建筑中的作用”。
- 实测：长页容器高 2358px；切到短页后容器仍高 2358px，实际内容底边为 920.86px，多出约 1437px 空白。
- 原因：`CurriculumFramePage.tsx:29` 用文档 `scrollHeight` 决定 iframe 高度，而课程布局的 `min-height:100vh` 又以当前 iframe 高度为下限，形成无法缩小的循环。
- 影响：返回入口距离内容变远；短页面看起来像有未加载的内容。
- 建议：切换课程时先解除旧高度，再根据内容的自然高度测量，避免使用包含当前 iframe 视口下限的尺寸。
- 证据：`course-short-after-long.png`。

### 3. [P2] 从节点详情返回节点库会丢失列表位置

- 复现：节点库滚动到有组织排水节点 → 打开节点 → 顶栏“返回节点库”。
- 实测：列表滚动位置 165px → 0px。
- 原因：`AppLayout.tsx:57` 对所有非首页、非课程路径统一执行滚动到顶部。
- 影响：连续查看多个节点时，每次都要重新寻找原来的分类和卡片。
- 建议：按路径保存列表滚动位置；前往新详情页时从顶部开始，返回已有列表时恢复原位置。

### 4. [P2] 节点详情仍使用旧顶栏高度，桌面底部被挤出视口

- 实测：1440×900 视口下，节点详情文档高 912px，底部超出 12px；截图中的底部说明被截断。
- 原因：`src/index.css:241–242` 仍扣除旧的 64px 顶栏，新的桌面顶栏实际高 76px。
- 影响：固定工作台出现多余页面滚动，底部内容无法完整呈现。
- 建议：顶栏与工作台共用高度变量，或由外层 Flex 布局分配剩余高度。
- 证据：`1440-_node_organized-drainage-01.png`。

### 5. [P2] 不存在的课程地址显示首页，缺少错误提示

- 复现：`/#/lesson/missing-page.html`。
- 实测：课程 iframe 内显示首页及首页轮播，未提示章节不存在。
- 原因：`CurriculumFramePage.tsx:12–13` 只检查后缀与路径格式，未检查课程是否存在；静态服务器的 SPA 回退将不存在的 HTML 返回为应用首页。
- 影响：失效书签或错误链接会把用户带到嵌入的首页，返回路径也变得难以理解。
- 建议：使用生成的课程清单校验地址，并为不存在或加载失败的课程显示明确的状态与返回入口。

### 6. [P2] 部分原有页面尚未完成新 UI 适配

- 作业训练和 AI 等占位页仍有正文中央的“返回主控制台”，同时顶栏已有“返回学习首页”；返回按钮的位置、文案和样式重复。
- 案例、资源、旧教材路径仍采用旧的标题尺寸与布局，未完全使用当前首页和课程页的页面体系。
- `LegacyCurriculumRedirect.tsx:10` 仍将旧课程入口引向旧教材页面，因此两套课程 UI 都能被访问。
- 建议：统一页面标题、空状态和返回入口；明确旧教材入口的兼容策略，避免同一课程出现两种展示方式。
- 证据：`390-_games.png`、`390-_curriculum_cases.png`；相关实现为 `GamesPage.tsx`、`PlaceholderPage.tsx`、`ResourcesPage.tsx`、`LegacyCurriculumRedirect.tsx`。

## 其他改进项

- 首页位于 `AppLayout.tsx:68–70` 的页面错误边界之外。懒加载首页模型模块失败时，无法使用项目现有的中文页面回退；应纳入错误边界。
- 课程返回首页后键盘焦点落到 `BODY`，没有回到原来的章节卡片或导航入口。滚动位置已保持，但键盘用户仍需重新定位。
- 节点库的顶栏随滚动保持可见，而课程顶栏处在完整高度的 iframe 内，父页面滚动后返回按钮会离开视口。初始位置和尺寸一致，滚动行为尚不一致。
- 构建中的 3D 依赖分块约 977KB（gzip 263KB）。这本身不证明卡顿；首页模型已延迟加载，应在后续以真实设备首屏时间及交互延迟判断是否继续拆分。

## 修复顺序

先处理首次板块定位、课程高度、列表返回位置和节点工作台高度，再处理课程错误页面及剩余 UI 适配。已验证正常的首页侧栏状态与模型画布保持逻辑应作为回归检查保留。

浏览器原始结果保存在 `results.json`，审计脚本为 `scripts/audit-ui-upgrade.mjs`。本轮未进行线上环境、浏览器扩展干扰或低端实体设备的性能测量，不能据此承诺所有设备上的帧率表现。
